# Movies Website

This is an application made with Next.js + TypeScript, Apollo Client for handling server state. UI is implemented using MUI.
It is a corporate website, where you can see information about different cvs, also you can perform crud operations with different entities.

## Installation

1. Clone the repository:

```bash
 git clone https://github.com/xrotgr/cv-Harbacheuski-Astapenka.git
```

2. Install dependencies:

```bash
 npm install
```

## Usage

To run the project, use the following command:

```bash
npm run dev
```
